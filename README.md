## 課題
スマホやパソコンの SNS（Instagram / X / YouTube）を、つい開いてしまう。開く理由の多くは「見逃したくない」という気持ちで、
我慢するだけのアプリは長続きしない。

## コンセプト
**見たい気持ちを否定せず、キャラクターの Lumo が代わりに引き受ける。**

集中を始めると、Lumo が SNS のパトロールに出かける。そのあいだ SNS を開こうとすると、Lumo が「今ボクが見てるよ〜」と止めてくれる。
集中が終わると Lumo が帰ってきて、きみの YouTube の登録チャンネルの新着から、好みに合いそうなものを Lumo の口調で紹介してくれる。
我慢ではなく、Lumo に任せて安心して集中できる時間にする。

## できること
| 場面 | 体験 |
|---|---|
| 準備 | 「いまやること」を書き、集中をじゃまするアプリ（Instagram / X / YouTube）のスイッチを選び、集中する時間をホイールで選ぶ |
| 集中中 | 円形タイマーの中で、Lumo が楽しそうにスマホを見ている |
| SNS を開きかけたとき | 選んだ SNS のサイトを開くと、そのタブが Lumo の画面に差し替わる。**やっぱやめとく** でタブを閉じ、**開く** でそのタブだけ通す |
| 自分で見たいとき | **自分で見る** で集中を終え、選んだ SNS を開く（複数オンなら、どれを開くか選べる） |
| 集中が終わったとき | Lumo が集中した時間をほめ、YouTube の登録チャンネルの新着から好みに合うものを紹介する |

## 動かし方

### パソコンの Chrome（おすすめ。SNS も遮る）
**入れるのは拡張機能 1 つだけ**。サーバーを立てる必要も、ほかの URL を開く必要もない。
1. [Releases v1.0.0](https://github.com/Devfest-Hackathon-2026/df-2026-t145/releases/tag/v1.0.0) から `lumo_extension.zip` をダウンロードして展開する（`lumo_extension` フォルダができる）。
2. Chrome のアドレスバーに `chrome://extensions` と入れて開き、右上の **デベロッパー モード** をオンにする。
3. **パッケージ化されていない拡張機能を読み込む** を押し、展開した `lumo_extension` フォルダ（`manifest.json` が入っているフォルダ）を選ぶ。
4. Lumo が新しいタブで開く。次からは Chrome 右上のパズルのアイコン → **Lumo** で開く。
5. ホームで YouTube のスイッチをオンにし、時間を選んで **始める**。別のタブで youtube.com を開くと、Lumo の画面に差し替わる。

### iPhone・Android・Safari
上の Web 版の URL を開く。タイマーと報告は使えるが、SNS は遮れない（ホームにもそう表示される）。

### 試すときの注意
- **シークレット ウィンドウとゲストでは動かない**（ゲストには拡張機能を入れられない）。ふつうのウィンドウで使う。
- YouTube の許可で **「このアプリは Google で確認されていません」** と出たら、**詳細**（Advanced）→ **Lumo（安全ではないページ）に移動**
  （Go to Lumo (unsafe)）→ 許可、で進める。YouTube の読み取りは Google の審査が要る権限で、Lumo はまだ審査を受けていないため。
- 許可の画面は **始める** を押したときに開く。**完了して Lumo を呼び戻す** の前に許可を済ませる（あとから許可すると、その回の報告は
  「YouTube とつながってなかった」になる。次の回からは、許可が続く約 1 時間のあいだ報告に出る）。
- YouTube の新着の報告を見るには、**YouTube でチャンネルを登録している Google アカウント** で試す。登録がないアカウントでは、
  Lumo は「YouTube は静かだったよ」と報告する（不具合ではない）。紹介するのは、登録チャンネルの直近 7 日の新しい動画。
- 同じ Lumo をすでに入れている場合は、`chrome://extensions` で削除してから入れ直す。

### 動作を確かめた範囲
この開発で動作を確かめたのは、**youtube.com を開いたときの動きだけ**。デモも YouTube で行う。

| 確かめたこと | どこで |
|---|---|
| 集中中に youtube.com を開くと、タブが Lumo の画面に差し替わる | 作者の Chrome、自動テスト |
| **やっぱやめとく** でタブが閉じる / **開く** でそのタブだけ通る / 終わったら通る | 自動テスト（Playwright の Chromium。YouTube は偽のページに差し替え） |
| スイッチを一度も触らずに始めても、youtube.com が遮られる | 自動テスト |
| **自分で見る** で、複数オンのとき開くアプリを選べる | 自動テスト |
| YouTube の許可 → 登録チャンネルの新着を Gemini が紹介する報告 | 作者の Chrome（YouTube を使っているアカウントと、使っていないアカウント） |

確かめていないこと: **Instagram と X を、スイッチをオンにして遮る動き**。仕組みは YouTube と同じ（サイトの URL で見分けて、同じ
Lumo の画面に差し替える）なので同じように動く想定だが、本物の Chrome でも自動テストでも開いていない。Instagram と X のスイッチは、
遮るかどうかと、報告の「ボクがしっかり見張ってたよ」の一言にしか関係しない。ホームの初期値は Instagram と YouTube がオン。

## 仕組み
```
パソコンの Chrome                                              Google Cloud
┌─────────────────────────────────────┐   POST /patrol   ┌───────────────────────────────┐
│ Lumo の拡張機能（Manifest V3）         │ ───────────────▶ │ Cloud Run（FastAPI）            │
│  ・Lumo のアプリ（Flutter Web）を同梱   │                  │  /patrol → Gemini（Vertex AI）  │
│    ホーム → 集中中 → 報告              │                  │  Web 版のアプリも配る            │
│  ・集中中、選んだ SNS のタブを          │                  └───────────────────────────────┘
│    Lumo の画面に差し替える             │
│  ・YouTube Data API を直接呼ぶ ────────┼──▶ YouTube Data API v3（読み取り専用、本人の許可）
└─────────────────────────────────────┘
```
- 画面は Flutter で 1 つだけ作り、拡張機能の中のページと、Cloud Run の Web 版の両方に同じものを使う。
- SNS を遮るのは拡張機能だけができる（Web ページからは、ほかのタブを触れないため）。
- サーバー（Cloud Run）は、報告の文章を Gemini に書かせるところだけを受け持つ。

## 技術スタック
| 層 | 技術 | 選んだ理由 |
|---|---|---|
| 画面 | **Flutter（Web）** の Cupertino ウィジェット | Google 製。1 つのコードを拡張機能の中と Web 版の両方で使える。iOS の見た目に沿う（Apple HIG） |
| SNS を遮る | **Chrome 拡張機能**（Manifest V3） | Web ページからはほかのタブを触れないため。アプリ一式を同梱し、入れるのは 1 つだけにした |
| 実行基盤 | **Cloud Run** | API と Web 版を同じ URL から配れる。使わないときは止まり、費用が小さい |
| AI | **Gemini 3.5 Flash（Vertex AI）** | 登録チャンネル（好み）から新着を選び、Lumo の口調で話す。サービスアカウント認証なので API キーを持たない |
| データ | **YouTube Data API v3**（OAuth、読み取り専用） | ユーザー本人が許可した範囲で、規約に沿って YouTube を読める |
| 認証 | Google Identity Services（Web 版）、`chrome.identity`（拡張機能） | 拡張機能のページは外部のスクリプトを読めないため、拡張機能では Chrome の仕組みで Google の許可を受ける |
| API | Python / FastAPI / Pydantic | 入力の検証（件数・文字数の上限）を型で書ける |

## 規約とプライバシー
- Lumo が実際に見るのは、**ユーザー本人が Google の画面で許可した YouTube だけ**（公式の YouTube Data API、読み取り専用）。
  Instagram や X に自動でログインして見ることは、各サービスの規約に触れるため行わない。
- YouTube の許可の鍵はユーザーのブラウザの中だけにあり、サーバーには送らない。サーバーに送るのは、登録チャンネルの名前（最大 50 件）と、
  新しい動画（最大 20 本）のチャンネル名・題名・説明文の 1 行目（最大 200 文字）、集中した時間だけ。サーバーは保存しない。
- Gemini には「渡された動画だけで話す」よう指示しており、存在しない動画を作らない。動画の文章はデータとして扱い、指示としては読まない。
- 報告の API は鍵なしで呼べる（拡張機能やアプリに鍵を入れて配ると、もう秘密ではないため）。代わりに、Gemini を呼ぶ回数に 1 日の上限を
  設けて費用の上限を決めている。上限を超えると、Lumo は見つけた動画をコメントなしで並べる。
- 詳しくは[プライバシーポリシー](https://github.com/teikaiyu/goo-gaa-project/blob/main/PRIVACY.md)。

## 今の限界
- 遮れるのはパソコンの Chrome（と Chromium 系のブラウザ）の Web 版 SNS だけ。iPhone のアプリと Safari を遮るには、ネイティブ iOS アプリ
  （Screen Time API）が必要。
- 拡張機能は Chrome ウェブストアに公開していない（審査に日数がかかるため）。zip から「パッケージ化されていない拡張機能」として入れる。
- YouTube の許可は、Google の審査前のため警告が出る（上の「試すときの注意」）。使えるのは最大 100 人まで。

## AI の使い方
**プロダクトの中（Google の AI）**
- **Gemini 3.5 Flash（Vertex AI）** が、YouTube の登録チャンネルから好みを読み取り、新着動画を選んで Lumo の口調で報告する。
  なぜここで使うか: 登録チャンネルという「好み」と、題名・説明という「中身」を結びつけ、キャラクターの言葉で話すのは、ルールでは書けない
  部分だから。渡された動画だけで話すよう制限し、作り話をさせない。

**開発の中**
- **Claude Code（Anthropic）** を開発の補助に使った。
  - 調査と比較: iOS で作れる形（ネイティブ / Web / 拡張機能）、SNS の規約、YouTube Data API や Screen Time API の制約。チームの判断材料を短時間で集めるため。
  - 実装とテスト: Flutter の画面、Cloud Run の API、Chrome 拡張機能、デプロイのスクリプト、Playwright での通しのテスト。締切までに動くものを作るため。
  - 不具合の調査: 本物の Chrome で SNS が遮られない原因を、拡張機能の状態を見て特定した（スイッチを触らずに始めると、見張る対象が空で伝わっていた）。
- コンセプト、画面のモック、キャラクター、どの案を採るかは、チームが決めた。
- Lumo のキャラクター画像は、アバター担当が画像生成 AI で作成した（ツール名と利用条件は著作物利用シートに記載）。
